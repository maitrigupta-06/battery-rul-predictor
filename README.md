# Battery RUL Predictor

Predicts the **Remaining Useful Life (RUL)** of Li-ion batteries using a Random Forest model trained on GAIL's Battery Prognostics dataset.

---

## Overview

| Item | Detail |
|---|---|
| Task | Predict RUL (cycles remaining before End-of-Life) |
| Model | Random Forest Regressor (200 estimators) |
| Validation | Leave-One-Battery-Out (LOBO) cross-validation |
| Overall MAE | **20.6 cycles** |
| Overall R² | **0.660** |

---

## Quickstart

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add data
Place the four `.mat` files from the NASA dataset into the `data/` folder:
```
data/B0005.mat
data/B0006.mat
data/B0007.mat
data/B0018.mat
```

### 3. Train the model
```bash
python src/train.py --data_dir data --models_dir models
```
This also runs LOBO cross-validation and prints metrics to the console.

### 4. Generate analysis plots
```bash
python src/analyse.py --data_dir data --plots_dir plots
```
Produces four figures in `plots/`.

### 5. Launch the web app
```bash
streamlit run src/app.py
```
Open http://localhost:8501 in your browser.

## Features Used

| Feature | Correlation w/ RUL | Importance |
|---|---|---|
| Mean Discharge Voltage | +0.85 | 73.3% |
| Min Discharge Voltage | −0.42 | 10.6% |
| Cycle Number | −0.85 | 6.5% |
| Discharge Duration (s) | +0.89 | 6.4% |
| Voltage Std Dev | +0.02 | 1.5% |
| Mean Temperature | −0.43 | 1.2% |
| Max Temperature | −0.37 | 0.6% |

## LOBO Cross-Validation Results

| Battery | MAE (cycles) | RMSE (cycles) | R² |
|---|---|---|---|
| B0005 | 19.1 | 22.2 | 0.711 |
| B0006 | 7.9 | 11.4 | 0.902 |
| B0007 | 40.3 | 42.3 | 0.240 |
| B0018 | 13.7 | 16.3 | 0.762 |
| **Overall** | **20.6** | **26.3** | **0.660** |

> B0007's weaker performance (R²=0.24) reflects its distinct aging curve relative to the training batteries, a known challenge in cross-battery generalization.

---

## EOL Definition
End-of-Life is defined as **30% capacity fade** from rated 2 Ahr → **1.4 Ahr threshold**, consistent with NASA dataset convention.
